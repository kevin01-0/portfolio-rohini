- Featured projects: Zenvy – AI Lifestyle & Wellness, AUTO RIDE, Ableton, and Monogram

- Contact and social links from the reference portfolio

## Add your portrait later
The previous portrait and AI-generated portrait have intentionally not been included. When you send your preferred image, add it to `public/assets/` and update the `profile.portrait` entry in `src/data/portfolio.ts`.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

The original dark/cinematic colour theme is preserved. Project descriptions and links are based on the public reference portfolio; no education, job history, awards, or certifications have been invented where the reference site did not provide them.
